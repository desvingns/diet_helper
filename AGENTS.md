  `D:/Pet/archive/MyDietHelper/<YYYY-MM-DD>/<relative-path>` with an index entry.
- Preserve the intentionally verbose Clean Architecture. See `CLAUDE.md` for
  implementation guidance and `STATE.md` for delivery status. Tests use fakes.

  turn each requirement into a generic multi-user fitness platform.

  exists, `.local/training/athlete-profile.md`. Load evidence and design details
  on demand. The private profile is intentionally Git-ignored; if absent on a
  different machine, ask for the missing context rather than inventing it.
- Keep symptoms, videos and personal training/diet data project-local. Separate
  self-reports, observations, estimates and diagnoses. Do not treat historical
  records or guessed restart maxima as verified current capacity.

  clearance. Label proposed rules and activation status explicitly.
