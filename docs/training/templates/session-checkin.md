For detailed feedback, record each set separately. A range or whole-workout
effort estimate must be labeled as such rather than copied to individual sets.
RIR-based set RPE: approximately 6 = 4+ reps left, 7 = 3, 8 = 2, 9 = 1,
10 = no more reps with comparable technique. It is not a pain scale.
