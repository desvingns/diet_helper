# Launcher icon concepts — 2026-10-21

Five separately generated PNG concepts, using the built-in image_gen tool.
Exact prompts are in `prompts.json`; open `index.html` for a numbered gallery
with 48 px and 32 px previews. These are selection concepts; launcher wiring
and Android adaptive/monochrome variants await the owner's selected number.

1. `01-plate-leaf.png` — nutrition-first plate and leaf.
2. `02-apple-strength.png` — apple and dumbbell.
3. `03-balance-bowl.png` — bowl and greens.
4. `04-progress-ring.png` — completion ring and check.
5. `05-heart-barbell.png` — heart and strength.

The generated silhouettes and crop should be checked in actual Android masks
when integrating a selected concept. Originals are preserved here.
